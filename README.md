# Kamiwaza installation scheduling — design demo

A static, browser-only demonstration of a possible installation-team booking experience. **No real availability, bookings, calendar connections, invitations, or video meetings.**

The name/email fields contain fixed fictional examples. Demo interactions stay in memory within one tab and reset on reload. The application sends no API calls and stores no personal information. GitHub Pages may log ordinary site requests.

Open `index.html` in a browser or serve these files with any static server. Run `node --test demo.test.js` to test the sample interactions. No dependencies or build step are required.

This repository contains only sanitized demo assets and fresh history. It is a project showcase, not a production booking service or commercial SaaS. Any real scheduling service would require a separate secure backend and an appropriate hosting plan.
